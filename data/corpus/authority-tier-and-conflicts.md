# Authority tiers and how conflicts are handled

This is a system note, not an agency publication. It documents how this corpus
is tiered. It carries no obligations and must not be cited as an obligation
source.

- **primary** — a statement of obligation or advisory attributable to an issuing
  agency and verified against a retrieved agency page.
- **secondary** — agency-attributable material of lesser operational force, or
  material whose detail was not retrieved.
- **explanatory** — schema descriptions, and interpretations authored for this
  system that apply primary rules to a specific operational situation. These
  restate; they never add.

When two `primary` documents from different agencies appear to conflict, the
conflict is surfaced to the user with both sources rather than silently
resolved. Agencies write for different populations and activity profiles, and an
apparent conflict is usually a scope difference that the user is better placed
to resolve than this system is.

An `explanatory` document never overrides a `primary` one, and a permissive
statement appearing only in an `explanatory` document is not a basis for
permitting an activity.
